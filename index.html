혼자금고 개인정보 처리방침

시행일: 2026년 10월 31일

혼자금고(이하 "앱")는 사용자의 사진·영상·파일·메모를 사용자의 기기 안에서만 암호화해 보관하는 앱입니다. 개발자는 사용자의 어떤 정보도 수집하거나 서버로 보내지 않습니다.

1. 수집하는 개인정보

없습니다. 앱에는 인터넷 권한이 없어서 어떤 정보도 기기 밖으로 전송할 수 없습니다. 회원가입, 로그인, 광고, 분석 도구(통계 수집), 크래시 수집 도구가 없습니다.

2. 기기 안에서 처리되는 정보

사용자가 앱에 넣은 다음 정보는 앱 전용 저장공간에서 처리되며 개발자나 제3자가 볼 수 없습니다.

  • 사진, 영상, 파일, 메모와 그 목록(이름·크기·날짜), 앨범, 사진 속에서 읽어 낸 글자(검색용)
  • 설정값(화면 밝기, 자동 잠금 시간 등)
  • 침입 기록 사진(켠 경우에만, 비밀번호를 틀렸을 때 전면 카메라로 찍은 사진)

파일은 파일마다 따로 AES-256-GCM 으로 암호화되며, 열쇠는 사용자의 비밀번호와 복구 코드로만 풀립니다. 비밀번호와 복구 코드는 개발자가 알 수 없고 복구할 수 없습니다. 둘 다 잃어버리면 금고를 열 수 없습니다.

3. 권한과 사용 목적

권한사용 목적
카메라금고 카메라로 사진·문서를 찍을 때, 그리고 침입 기록을 켠 경우 비밀번호를 틀렸을 때 전면 카메라로 찍을 때
사진 및 동영상(미디어) 읽기'찍어 둔 스크린샷 정리'에서 스크린샷 목록을 보여 주고, 사용자가 고른 것만 금고로 가져올 때. 선택 사항이며 허용하지 않아도 사진 고르기로 가져올 수 있습니다
생체 인식(지문·얼굴)금고 열기. 생체 정보는 안드로이드 시스템이 관리하며 앱은 인증 결과만 받습니다
화면 캡처(안드로이드의 캡처 허락 창)'금고로 캡처'를 쓸 때마다 사용자가 허락한 한 장만 찍어 곧바로 암호화합니다
포그라운드 서비스, 진동위 캡처가 진행되는 동안 알림 표시, 캡처 완료 알림 진동

앱은 인터넷, 위치, 연락처, 마이크, 전화, 문자 권한을 쓰지 않습니다.

4. 사용한 제3자 구성요소

  • Google ML Kit 글자 인식: 사진 속 글자를 읽습니다. 모델이 앱 안에 들어 있어 기기 안에서만 동작합니다. 이 라이브러리에는 사용 통계를 보내는 코드가 포함되어 있으나, 앱에 인터넷 권한이 없어 전송되지 않습니다.
  • OpenCV, AndroidX(CameraX 포함): 문서 모서리 찾기, 카메라, 앱 기반
  • 구성요소와 라이선스 목록은 앱의 설정 > 오픈소스 라이선스에서 볼 수 있습니다.

5. 보관과 삭제

  • 모든 정보는 앱을 삭제하면 함께 삭제됩니다. 개발자는 사본을 가지고 있지 않으므로 삭제된 정보를 되돌려 드릴 수 없습니다.
  • 사용자가 만든 백업 파일(.hjvault)은 사용자가 고른 위치에 저장되며 복구 코드로만 열립니다. 보관과 삭제는 사용자의 책임입니다.
  • '내보내기'로 꺼낸 파일은 암호화되어 있지 않습니다. 다 쓴 뒤 지워 주세요.
  • 앱의 자동 백업과 클라우드 백업은 꺼져 있습니다.

6. 아동

앱은 개인정보를 수집하지 않으므로 연령에 따른 수집 제한이 해당하지 않습니다. 다만 앱은 성인 사용자를 대상으로 합니다.

7. 방침의 변경

방침이 바뀌면 이 문서를 고치고 시행일을 갱신합니다. 앱이 정보를 수집하거나 전송하는 방식으로 바뀌는 경우에는 앱 업데이트 설명에도 알립니다.
